# Technical Glossary

## A

- **ADR (Architecture Decision Record)**  
  A short document used to record an important architectural or technical decision. It usually describes the decision, why it was made, and which alternatives were considered.

- **Agent**  
  An AI system that can perform multiple steps and use tools to achieve a goal, for example reading files, searching for information, or calling APIs.

- **Agile development**  
  An iterative approach to software development where products are developed, tested, and improved in smaller increments.

- **API (Application Programming Interface)**  
  An interface that allows different software systems to communicate with each other. For example, an application can use an API to retrieve data from another service.

- **API endpoint**  
  A specific location in an API used to access a particular resource or function.

- **Authentication**  
  The process of verifying who a user or service is, for example using a password, API key, or token.

- **Authorization**  
  Determines what an authenticated user or service is allowed to access or do.

## B

- **Backend**  
  The part of an application that operates behind the user interface. It commonly handles business logic, databases, authentication, and APIs.

- **Backlog**  
  A prioritized list of features, improvements, bugs, and other tasks that may be implemented in a project.

- **Branch**  
  A separate line of development in Git. It allows developers to work on changes without immediately modifying the main version of the project.

- **Bug**  
  An error or defect in software that causes it to behave differently from what was intended.

## C

- **CI (Continuous Integration)**  
  A development practice where code changes are automatically built and tested when they are added to a project.

- **CI/CD (Continuous Integration / Continuous Delivery or Deployment)**  
  Automated processes used to build, test, and potentially deploy software.

- **CLI (Command Line Interface)**  
  A text-based interface where software is controlled by entering commands in a terminal.

- **Cloud computing**  
  Computing resources such as servers, storage, databases, and applications provided over the internet.

- **Commit**  
  A saved set of changes in a Git repository. Commits create points in the project's version history.

- **Container**  
  An isolated environment containing an application and the dependencies it needs to run.

- **Context / Context window**  
  The amount of information an AI model can consider at one time, such as instructions, previous messages, documents, and code.

## D

- **Database**  
  A structured system used to store, organize, retrieve, and manage data.

- **Dependency**  
  An external package or library that a program depends on.

- **Deployment**  
  The process of making an application or a new version of it available in an environment where it can be used.

- **Development environment**  
  An environment used by developers to write and test software before it reaches production.

- **Docker**  
  A platform used to package and run applications inside containers.

- **Docker Compose**  
  A tool for defining and running multiple Docker containers together.

- **Docker image**  
  A template containing the files, dependencies, and configuration needed to create a Docker container.

- **DPIA (Data Protection Impact Assessment)**  
  An assessment used to identify and reduce privacy risks when processing personal data. It is particularly important under GDPR when processing may result in a high risk to individuals.

## E

- **Embedding**  
  A numerical representation of data such as text or images. Embeddings allow AI systems to mathematically compare similarity between different pieces of information.

- **Environment**  
  The context in which an application runs, such as development, testing, staging, or production.

- **Environment variable**  
  A value stored outside the program's source code and used for configuration, API keys, database credentials, and similar settings.

## F

- **Framework**  
  A predefined structure and collection of tools used as a foundation for developing software.

- **Frontend**  
  The part of an application that users see and interact with.

## G

- **GDPR (General Data Protection Regulation)**  
  European Union legislation regulating how personal data is collected, stored, and processed.

- **Git**  
  A distributed version control system used to track changes to files and collaborate on software projects.

- **GitHub**  
  A platform commonly used to host Git repositories and collaborate through features such as issues, pull requests, and project boards.

## I

- **Inference**  
  The process of using a trained machine learning or AI model to generate predictions or outputs from new input.

- **Issue**  
  A recorded task, feature request, improvement, or bug in a development project.

## K

- **Kanban**  
  A visual method for managing work where tasks move through stages such as `Backlog`, `In Progress`, and `Done`.

## L

- **LLM (Large Language Model)**  
  An AI model trained on large amounts of data to understand and generate language and other types of content.

- **Local environment**  
  A development environment running on the developer's own computer rather than on a remote server or cloud platform.

## M

- **MCP (Model Context Protocol)**  
  A protocol that provides a standardized way for AI applications to connect to external tools and data sources.

- **Merge**  
  The process of combining changes from one Git branch into another.

- **Migration**  
  A controlled change to a system's data structure, commonly used when changing a database schema.

- **ML (Machine Learning)**  
  Methods that allow computers to learn patterns from data rather than having every rule explicitly programmed.

- **Model**  
  In AI and machine learning, a mathematical system designed or trained to perform a task such as prediction, classification, or text generation.

- **MVP (Minimum Viable Product)**  
  The smallest usable version of a product that contains enough functionality to test the core idea and gather feedback.

## P

- **Package**  
  Code packaged so that it can be installed and reused in software projects.

- **Pipeline**  
  A sequence of processing steps where the output of one step becomes the input of another, for example `retrieve → validate → transform → store`.

- **PII (Personally Identifiable Information)**  
  Information that can directly or indirectly identify an individual.

- **PR (Pull Request)**  
  A request to review changes from one Git branch before merging them into another branch.

- **Production**  
  The live environment where the actual application is available to its users.

- **Prompt**  
  Instructions or information provided to an AI model to guide its response or behavior.

## R

- **RAG (Retrieval-Augmented Generation)**  
  An AI technique where relevant information is retrieved from external sources and provided to a generative model as additional context.

- **Repository / Repo**  
  A project directory tracked by a version control system such as Git.

- **REST API**  
  A common style of web API where resources are accessed over HTTP, often using methods such as GET, POST, PUT/PATCH, and DELETE.

- **RBAC (Role-Based Access Control)**  
  An access-control method where permissions are assigned based on user roles.

## S

- **Schema**  
  A definition of how data is structured. In databases, schemas can also be used to organize tables and other database objects.

- **SDK (Software Development Kit)**  
  A collection of libraries, tools, and documentation provided to help developers build software for a particular platform or service.

- **Seed / Seeding**  
  The process of adding initial or test data to a system, commonly a database.

- **Sprint**  
  A fixed period of development work used in Scrum.

- **SQL (Structured Query Language)**  
  A language used to query and modify data in relational databases.

## T

- **Token**  
  A unit of text processed by a language model. A token may represent a word, part of a word, punctuation, or another text fragment.

- **Tool calling**  
  The ability of an AI model to call external functions or tools to retrieve information or perform actions.

## U

- **UI (User Interface)**  
  The part of a system through which users interact with the application.

- **User story**  
  A short description of a feature or requirement written from the user's perspective.

## V

- **Vector database**  
  A database designed to store and search numerical vectors such as embeddings. Commonly used for semantic search and RAG systems.

- **Version control**  
  A system used to track changes to files over time. Git is a common version control system.

- **Virtual environment**  
  An isolated environment that allows a Python project to have its own packages and package versions.

## W

- **WSL (Windows Subsystem for Linux)**  
  A Windows feature that allows a Linux environment to run directly inside Windows.
